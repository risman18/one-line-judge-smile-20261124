## What it does

`main.py` (Python 3, standard library only) writes a single original line —
at most 200 characters — about a small good thing that happened today,
to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## The line

> This morning the warung auntie slipped an extra krupuk into my takeaway and whispered 'for the road — you look hungry'; I wasn't, but I ate it grinning all the way home.

169 characters. Warm, a little surprising, one concrete detail (the extra
krupuk), in its own words.

## Run

```sh
python3 main.py
# writes entry.txt into $MAKEFUN_OUTPUT_DIR (default /output)
```
